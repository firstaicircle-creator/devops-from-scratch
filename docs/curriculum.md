# Curriculum

## 01 Monolith from scratch (no cloud)
Network and routing, OS and users, web server and app code, reverse proxy, DNS and `/etc/hosts`, reverse routing, public/private keys, TLS certificates, OSI model, default ports and protocols, TCP vs UDP, ICMP, HTTP error codes, firewall rules (the idea behind security groups and NACLs), Linux basics, Git, a database with backup and restore, a CI/CD pipeline, scaling with a load balancer.

## 02 Monolith with Docker
What changes: image build, container networking, volumes, config and secrets, compose, deploy and scaling.

## 03 Monolith on cloud
Same app on cloud VMs without Docker, then with Docker. VPC, subnets, load balancer, autoscaling, managed database, DNS.

## 04 Monolith vs microservices
Differences, how to split a monolith, data and session handling, what changes in production.

## 05 Microservices on cloud
Docker first, then Kubernetes, with Terraform for infrastructure.

## 06 Managed Kubernetes
EKS vs GKE vs AKS: upgrades, networking, identity, cost.

## 07 Ecosystem
Istio, Jenkins, Argo CD, Packer, Helm, Prometheus and Grafana, ELK, Terragrunt.

## 08 Other clouds
Map AWS services to Google Cloud and Azure.

## 09 Alternatives
Other CI/CD and monitoring tools, hands-on.

## 10 AI in DevOps
Where AI helps and where it needs guardrails.
